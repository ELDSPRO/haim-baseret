# חיים בסרט

**משחק קריירה בעולם הקולנוע — מהשוט הראשון עד השטיח האדום.**

[למשחק בדפדפן](https://eldspro.github.io/haim-baseret/)

משחק דפדפן מקורי בעברית על יצירת סרטים, פרנסה, קשרים והחיים שביניהם. בוחרים בקובי, נועה, אמיר או תמר ובונים קריירה מול היריב איתי, מהסרט הראשון ועד לפרישה.

## בתוך המשחק

- ארבע דמויות ושלוש רמות קושי.
- שישה ז׳אנרים, 72 שמות ותקצירים וחמישה היקפי הפקה.
- צילום ועריכה בימים מצטברים: כל לחיצה משלימה יום אחד.
- צוות מקצועי, קרנות, מימון המונים וחוזי הפקה וקופרודוקציה.
- עבודות, סוכנים, מפיקים, פסטיבלים וארון פרסים.
- תל אביב, אתונה, ברלין, לונדון ולוס אנג׳לס, עם תוכן מקומי משתנה.
- זוגיות, נדל״ן ומניות בדיוניות, לאורך קריירה מגיל 23 עד 85.
- הפתעות טובות ותקלות שמותאמות להיקף ההפקה.
- התאמה למחשב ולנייד, שמירה אוטומטית ופאנל מצב קבוע בגלילה.
- שלושה מצבי צבע: קלאסי, בהיר וכהה. הבחירה נשמרת בנפרד מהתקדמות המשחק וזמינה גם במסך הפתיחה.
- הדרכה אינטראקטיבית בצעדים: פתיחת סרט, משמרת ומנוחה אמיתיות, והיכרות עם המערכות המרכזיות. אפשר לדלג, להמשיך אחרי רענון או לפתוח מחדש דרך ״איך משחקים״.

השמירה מקומית לדפדפן ולכתובת המשחק. אין כרגע סנכרון שמירות בין מכשירים. הכלכלה והארגונים הם חלק מסימולציה בדיונית ומקוצרת. האיורים המקוריים נוצרו בעזרת כלי יצירת תמונות.

## פיתוח מקומי

נדרשים Node.js 22 ומעלה ו־Python 3. אין צורך בשרת נתונים או בהתקנת חבילות בזמן ריצה.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

פותחים את [המשחק המקומי](http://127.0.0.1:4173/).

## בדיקות ובנייה

```sh
python3 scripts/test-all.py
python3 scripts/build-site.py
```

הבדיקות כוללות מסלולי קריירה מלאים, מימון, הפקה, פסטיבלים ותאימות לשמירות קודמות. נתוני `tests/fixtures` הם מצבי בדיקה יזומים של המשחק. חלק מהסוויטות מייצרות מחדש מצבים כאלה; בדיקות גבול מפרידות במפורש בין אימות חוקי המשחק לבין בדיקת איזון.

קובצי ההפצה נוצרים בתיקיית `dist` מרשימה מפורשת של קובצי המשחק. הבדיקות, נתוני הבדיקה והתיעוד אינם חלק מהאתר המפורסם.

## פרסום

הענף הראשי הוא `codex/main`. כל עדכון אליו מפעיל בדיקות ובנייה, ורק לאחר הצלחה מפרסם את `dist` ל־GitHub Pages. בקשות שינוי מפעילות בדיקות ללא פרסום.

GitHub Pages מוגדר לפרסום באמצעות GitHub Actions. אפשר להפעיל שוב את הפרסום ידנית מעמוד Actions.
